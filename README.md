# Claude Plugins — Real Life Org

Claude Code Skills und Tools für das Real Life Team.

## Installation

```shell
/plugin marketplace add real-life-org/claude-plugins
/plugin install rfc-tools@real-life-tools
```

## Verfügbare Skills

| Skill | Beschreibung |
|-------|-------------|
| `/rfc` | Neuen RFC erstellen (Branch, Datei, PR) |
| `/rfc-status` | Übersicht aller offenen RFCs und deren Status |
